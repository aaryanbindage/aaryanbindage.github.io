# aaryanbindage.github.io

Project index at **https://aaryanbindage.github.io/**.

`build.mjs` builds the page from the GitHub API every day: each public, non-fork repo that has a description, plus `sitemap.xml` and `robots.txt`. The sitemap covers every project's GitHub Pages site under this domain, so one Google Search Console property indexes them all.

To verify with Google Search Console, add the `googleXXXX.html` file it gives you to the repo root and push.
